# Vocatune


## Website Vocatune untuk apa?
Website ini dirancang bagi seseorang yang ingin memperkaya kosa kata bahasa Inggris (Vocabulary) tanpa terasa sedang belajar, yaitu melalui game tebak lagu yang memanfaatkan potongan lirik populer, sehingga proses mengingat kata-kata baru menjadi lebih santai.

---

## Halaman yang ada di website Vocatune
 - ***Leaderboard***
 Membandingkan pemain dengan skor 
 - ***Profile*** 
 Melihat  Info Pribadi Seperti nama, password, akun gmail yang digunakan

 - ***Game mode*** 
  Ada mode:
  - Easy (Pemain menebak lirik lagu dengan cara Pilihan ganda) 
  - Medium (Pemain menebak lirik lagu dengan cara mengetik)
  - Hard (Mode mengetik endless. Jawab secepat mungkin untuk mempertahankan sisa waktu agar kamu bisa terus bermain)
 - ***Statistik***
  Setelah bermain game di mode apa saja akan memunculkan page ini


## Tools yang saya gunakan
- [Vercel](https://vercel.com/) = Platform yang digunakan untuk menghosting aplikasi web ini agar dapat diakses secara online
- [Supabase](https://supabase.com/) = Platform database untuk menyimpan data Vocatune yang terus diperbarui seiring berjalannya waktu.
- [Github](https://github.com/) = Tempat menyimpan, melacak perubahan, dan mengelola kode proyek Vocatune.
- [Edge](https://www.microsoft.com/edge) = Browser yang digunakan untuk menjalankan, dan menguji aplikasi selama proses pembuatan Vocatune.
- [Pixi.js](https://pixijs.com/) = Libary khusus yang digunakan agar game Vocatune tetap ringan, dan terhindar dari lag saat dimainkan.
- [HTML] = Bahasa dasar yang digunakan untuk membangun kerangka utama halaman utama Vocatune.
- [CSS] = Bahasa yang digunakan untuk menghias tampilan Vocatune, seperti mengatur warna, jenis hurf, dan tata letak agar nyiman dilihat oleh pemain.
- [JavaScript (JS)] = Bahasa pemrograman yang digunakan untuk menjalankan logika mode permainan, memeriksa ketepatan jawaban, dan menghitung batas waktu.
